# 🔐 CodeVault — Code Snippet Manager

A responsive web application for saving, organizing, searching, and reusing code snippets in one place.

## ✨ Features

* 📝 Create and save code snippets
* ✏️ Edit existing snippets
* 🗑️ Delete snippets
* 📋 Copy code to the clipboard
* 🔎 Search titles, descriptions, languages, and code
* 🏷️ Filter snippets by programming language
* 📊 View snippet and language statistics
* 💾 Persist snippets using browser LocalStorage
* 📱 Responsive interface for desktop and mobile

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Browser LocalStorage API
* Clipboard API

## 🌐 Live Demo

**[Launch CodeVault](https://arhamkhancr608-rgb.github.io/codevault-snippet-manager/)**

## 🚀 Getting Started

1. Open the live demo, or download/clone this repository.
2. Open `index.html` in your browser.
3. Create a snippet by entering a title, language, and code.
4. Search, filter, edit, copy, or delete snippets as needed.

## 💾 Data Storage

CodeVault stores snippets in the current browser using LocalStorage. Data is not synchronized across devices or user accounts.
